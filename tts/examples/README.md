# Examples Directory (`examples`)

This directory contains standalone, executable scripts demonstrating features of the `gemini_speech` library.

## Files
- [`list_models_demo.py`](list_models_demo.py): Fetches and filters available speech/TTS models from Google AI Studio / Gemini API.
- [`list_voices_demo.py`](list_voices_demo.py): Lists available preset voice profiles (`Puck`, `Charon`, `Kore`, `Fenrir`, etc.) and their vocal characteristics.
- [`generate_speech_demo.py`](generate_speech_demo.py): Complete end-to-end speech generation demo using `gemini-3.8-flash-tts` with rich acoustic styling, expressive emotion prompts, and automatic PCM-to-WAV conversion.
