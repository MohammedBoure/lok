# Inputs Directory

This directory stores raw incoming media assets and project specifications for the video production pipeline.

## Files & Subdirectories
- [`source_fox_cub.mp4`](source_fox_cub.mp4): Raw source video clip featuring a young fox cub in a natural forest environment.
- [`source_squirrel.mp4`](source_squirrel.mp4): Raw source video clip featuring an energetic baby squirrel.
- [`video_request.md`](video_request.md): User requirements, narrative script, tone guidelines, and post-production delivery specifications.
- `mobile_uploads/`: Ingestion directory for raw smartphone camera recordings uploaded via the mobile API server (`POST /api/upload-and-process`).
